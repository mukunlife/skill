# 差异分析结果说明

- 比较方向：**treat vs control**；log2FoldChange > 0 表示在 treat 中表达更高。
- 样本：control n=3，treat n=3，共 300 个基因。
- 数据类型：counts（非负整数且最大值 > 20，自动判为原始 counts）。
- 预处理：CPM 归一化后取 log2(x + 1)。
- 检验方法：Welch t 检验（双侧）。
- 多重检验校正：Benjamini-Hochberg（padj 为校正后 P 值）。
- 筛选标准：|log2FoldChange| >= 1 且 padj < 0.05。
- 结果：显著基因 **20** 个（上调 5，下调 15）。
- 零方差基因：5 个；P 值为 NaN 后按 1 处理的基因：5 个。

## 校验与局限

- 样本与分组校验：通过。
- 提示：有 5 个基因在所有样本中均为 0，将保留但标记为零方差
- 本方法在 log2 CPM 上做 Welch 检验，不等同于 DESeq2/edgeR 的负二项模型；
  小样本或低表达基因较多时，P 值可能偏乐观，正式分析建议使用 DESeq2/edgeR 复核。
- 火山图仅反映效应量与显著性，判断候选基因时还应结合 base_mean（表达丰度）。
