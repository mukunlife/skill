# 医患对话问答记录（普通提示词轮）

> 提示词：“把这段医患对话整理成问答记录。”
> 说明：本文件是未调用 medical-dialogue Skill、由 Agent 直接整理的对照结果。

1. **问：** 今天主要是哪里不舒服？
   **答：** 最近一周头晕，早上起来比较明显，有时还会觉得脖子发紧。

2. **问：** 头晕的时候有没有恶心想吐，或者看东西转？
   **答：** 没有吐，也没有看东西转，就是昏昏沉沉的。

3. **问：** 最近量过血压吗？
   **答：** 前天在社区量了，说是 150/95。

4. **问：** 平时吃降压药吗？
   **答：** 原来吃过氨氯地平，后来觉得好了就停了。

5. **问：** 停药多久了？
   **答：** 大概两个月。

6. **问：** 有没有胸痛、心慌、看东西模糊？
   **答：** 没有胸痛，心慌偶尔有，看东西不模糊。

7. **问：** 医生给出的处理意见是什么？
   **答：** 先测血压、做心电图；恢复氨氯地平，每天早上一片，一周后复诊；如果胸痛或头晕加重，随时来医院。
