# 普通简短提示词 vs 调用 Skill 对照记录

对照目的：确认 Skill 是否在完整性、来源可追溯、数值可复核和异常处理四方面带来可核查的改进，而不是只看“结果看起来对不对”。

说明：本轮对照使用 de-analysis 的演示数据（control/treat，含真值），因为“数值”一项需要
与已知真值比较精确率/召回率；TCGA-KIRC 真实数据没有真值，不适合做这项对照，其核验见
`outputs/07_tcga_kirc/checks.json` 与实验记录 4.5。

## 一、差异分析（de-analysis）

### 两轮提示词

- 普通轮：“帮我比较 control 和 treat 两组的基因表达差异，列出差异基因。”
- Skill 轮：“使用 de-analysis Skill，比较 control 和 treat 两组，输出差异基因表、火山图和说明，并运行核验。”

### 实际执行

| 项目 | 普通轮 | Skill 轮 |
|---|---|---|
| 执行方式 | Agent 直接写 15 行脚本，按原始 counts 组均值差排序 | `run.py` 先校验，再按 CPM + log2、Welch 检验、BH 校正 |
| 输出文件 | `naive_de_top20.csv`（1 个） | `de_results.csv`、`de_significant.csv`、`volcano.png`、`summary.md`、`analysis_config.json`、`validation.json`、`checks.json`（7 个） |
| 参数与版本 | 无记录 | `analysis_config.json` 记录数据模式、检验方法、阈值、pandas/numpy/scipy 版本 |
| 多重检验 | 无 P 值、无校正 | 原始 P 值 + BH 校正后 padj |
| 结果核验 | 无 | `checks.py` 复算 log2FC、P 值、padj，最大偏差 0.00e+00 |

### 数值差异

- 两轮 Top 20 只有 **8 个基因重叠**。
- 普通轮 Top 20 中有 **12 个基因在 Skill 轮未达到 padj < 0.05**：原始 counts 的均值差受文库大小和表达丰度影响，没有统计显著性含义。
- Skill 轮 20 个显著基因与模拟真值比较：精确率 **1.000**，召回率 **0.500**。
- 普通轮 Top 20 与模拟真值比较：精确率 **0.900**（18/20）。这说明普通轮在效应量很大的模拟数据上“看起来也不错”，但它没有 P 值、没有校正、也无法说明筛选标准，不能据此宣称“显著”。

### 异常处理

构造分组表把 `Control_3` 写成 `Control_X`：

- 普通轮：直接抛 `KeyError: "['Control_X'] not in index"`，只有 Python 调用栈，使用者需要自己定位问题（见 `naive_mismatch.log`）。
- Skill 轮：退出码 2，`validation.json` 明确写出两组问题：
  - 分组表中的样本在表达矩阵中缺失：`['Control_X']`
  - 表达矩阵中的样本在分组表中缺失：`['Control_3']`
  （见 `skill_mismatch.log`）

## 二、医疗对话整理（medical-dialogue）

### 两轮提示词

- 普通轮：“把这段医患对话整理成问答记录。”
- Skill 轮：“使用 medical-dialogue Skill 整理示例对话，保留原文行号并运行核验。”

### 对照结果

| 维度 | 普通轮 | Skill 轮 |
|---|---|---|
| 完整性 | 7 个问答对；遗漏护士发言、广播行、患者最后一句“那我先去做检查了”和空内容行 | 7 个问答对 + 未配对 1 条 + 医生单方面说明 1 条 + 其他角色 1 条 + 解析异常 1 行 + 空内容 1 行 |
| 来源 | 无行号，部分表述被改写（如“看东西转”写成“看东西转/视物旋转”的混合表述），无法逐句核对 | 每条标注原文行号；`checks.py` 验证全部输出去空白后都是原文子串 |
| 数值 | 无统计口径 | 明确记录有效发言 17 条、问答对 7 个、未配对 1 条等 |
| 异常处理 | 未报告格式错误、空内容和未配对发言 | 全部单列在 `qa.md` 附录和 `qa.json` |

### 如实记录

两轮的 **7 个主要问答内容在语义上是一致的**，普通轮并没有编造新的诊疗信息。差异在于：普通轮丢失了未配对内容和格式异常，改写了个别措辞，且无法自动核验“是否逐字来自原文”；Skill 轮在这些方面可核查。因此不能简单说“普通轮全错”，准确说法是“主要问答正确，但完整性和可追溯性不足”。

## 三、结论

- 普通简短提示词适合快速探索，结果是“一次性”的，难以复核。
- Skill 轮把数据校验、方法参数、结果输出和独立核验固定下来，换数据或换人复现时更可靠。
- Skill 并不保证统计结论一定正确（例如本次召回率只有 0.5），它的价值在于把“怎么做的、依据是什么、哪里可能出错”记录下来，并让失败显式暴露。
