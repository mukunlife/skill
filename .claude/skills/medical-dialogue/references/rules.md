# 对话整理规则

## 1. 输入格式

- 文件编码 UTF-8（可带 BOM）。
- 每条发言一行，推荐格式：`[时间] 说话人：内容`。
- 时间戳可省略；冒号可为中文 `：` 或英文 `:`。
- 空行忽略，不视为发言。
- 不以 Speaker 格式出现的行（如场景说明、无冒号的广播）记为 `parse_errors`，保留行号，不丢弃。

## 2. 说话人识别

| 角色 | 别名（不区分大小写，忽略首尾空格） |
|---|---|
| 医生 | 医生、医师、doctor、dr、dr. |
| 患者 | 患者、病人、patient |
| 其他 | 护士、家属、旁白等未列出的说话人 |

- 可通过 `--doctor-label`、`--patient-label` 追加自定义标签。
- 其他说话人的发言不参与问答配对，单独列入“其他发言”，避免把护士或家属的话误当成患者提问。

## 3. 合并规则

- 连续且说话人相同的发言合并为一条，文本之间用一个空格连接，行号保留为区间（如 `10-11`）。
- 不同说话人即使角色相同（如两位家属），也不合并。

## 4. 配对规则

按合并后的发言顺序扫描：

1. 患者发言，且紧邻的下一条是医生发言 → 组成一个问答对。
2. 患者发言，但下一条不是医生发言（或已是最后一条）→ 列入 `unmatched_patient`，注明“缺少医生回应”。
3. 医生发言，且前一条不是待配对的患者发言 → 列入 `doctor_notes`，注明“医生单方面说明”。
4. 其他角色 → 列入 `other_turns`。
5. 一条发言只能归入一个类别，不得重复计入。

## 5. 逐字保留要求

- 只允许删除：时间戳、说话人标签、行首尾空白。
- 不允许：改写、缩写、概括、同义替换、调整语序、补充标点之外的内容。
- 不允许补充原文没有的症状、诊断、检查、药物、剂量、随访建议。
- 不允许把医生的推测改写成确定结论。
- 原文有错别字或口语重复时保留原样；如确需说明，只能在报告外单独提示，不能改正文。
- 数字、单位、药名、剂量必须与原文一致。

## 6. 输出字段

`qa.md`：

- 标题与来源说明。
- 统计：原始行数、有效发言数、问答对数、未配对数、解析异常数。
- 问答记录：每条含问题、回答、原文行号。
- 附录：未配对内容、医生单方面说明、其他发言、解析异常。

`qa.json`：

```json
{
  "meta": {"source": "...", "title": "...", "total_lines": 0, "turns": 0,
           "pairs": 0, "unmatched": 0, "doctor_notes": 0,
           "other_turns": 0, "parse_errors": 0},
  "pairs": [{"pair_id": 1,
             "question": {"turn_id": 1, "line_no": "3", "speaker": "患者", "text": "..."},
             "answer": {"turn_id": 2, "line_no": "4", "speaker": "医生", "text": "..."}}],
  "unmatched_patient": [],
  "doctor_notes": [],
  "other_turns": [],
  "parse_errors": []
}
```

## 7. 核验要求

`scripts/checks.py` 必须验证：

1. `qa.md`、`qa.json`、`checks.json` 存在。
2. 每个输出文本（问题、回答、未配对、医生说明、其他）在去掉空白后，都是原始解析文本拼接结果的子串——证明没有新增内容。
3. 所有有效发言都被某个类别覆盖，且只覆盖一次。
4. 问答对数、未配对数等统计与 `qa.md` 中的数字一致。
5. 任一检查失败，退出码为 1，报告不得声称整理完成。

## 8. 异常处理

- 空内容（如 `医生：`）记为 `empty_content`，不生成空问答对。
- 全文没有可识别发言 → 退出码 2，提示检查格式和说话人标签。
- 文件不存在或编码错误 → 退出码 2，给出具体路径和错误信息。
