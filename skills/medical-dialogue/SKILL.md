# 医疗对话整理为问答记录

## 适用任务

- 把门诊、随访、问诊的医患对话文本整理成“问题—回答”结构。
- 需要保留原始表述、可逐条追溯到原文的整理任务。
- 需要显式标记“患者问了但医生没答”“医生单方面交代”等不完整片段。

## 不适用

- 根据对话下诊断、推荐用药或补充医学建议（本 Skill 只整理，不生成医学结论）。
- 对对话做摘要、改写、翻译或情绪分析。
- 音频转写（输入必须是已经转写好的文本）。

## 输入格式

UTF-8 文本，每行一条发言：

```text
[08:30:12] 医生：您好，请坐。今天主要是哪里不舒服？
患者：最近一周总觉得头晕。
```

- 时间戳 `[...]` 可省略。
- 说话人与内容之间用中文或英文冒号分隔。
- 支持的医生别名：医生、医师、doctor、dr；患者别名：患者、病人、patient。
- 其他说话人（如护士、家属）会被单独归入“其他发言”，不强行配对。
- 不符合格式的行不会被丢弃，而是记入 `parse_errors` 并在报告中列出。

## 执行流程

1. 读 `references/index.md`，再读 `references/rules.md`，确认逐字保留、配对和异常处理规则。
2. 运行整理脚本：
   ```bash
   python scripts/run.py --input <对话文本> --output-dir <输出目录> \
       [--title <标题>] [--doctor-label 医生] [--patient-label 患者]
   ```
3. 运行核验脚本：
   ```bash
   python scripts/checks.py --input <对话文本> --output-dir <输出目录>
   ```
   核验失败（退出码 1）时不得宣称整理完成。
4. 向用户报告：问答对数、未配对条数、解析异常条数、逐字追溯核验结果。

## 输出

| 文件 | 内容 |
|---|---|
| `qa.md` | 可阅读的问答记录；附未配对内容、医生单方面说明、其他发言、解析异常 |
| `qa.json` | 结构化数据：每个问答对的原文、行号、说话人；未配对与异常清单 |
| `checks.json` | 逐字追溯核验报告 |

## 必须遵守的规则（详见 references/rules.md）

- **逐字保留**：只去掉时间戳和“说话人：”标签，不改写、不概括、不润色。
- **不补充信息**：不得加入原文没有的症状、诊断、药物、剂量或建议。
- **不推断**：原文没写的内容，输出中也不能出现；不确定时保留原文。
- **可追溯**：每个问答对保留原文行号。
- **异常显式化**：未配对、空内容、格式错误的行必须单独列出，不能静默丢弃。

## 脚本说明

- `scripts/run.py`：入口，解析、配对并生成 `qa.md` / `qa.json`。
- `scripts/parse.py`：解析与配对的核心逻辑，也提供核验用的文本归一化函数。
- `scripts/checks.py`：逐字追溯核验，确保输出没有新增内容。

不要用模型直接改写对话来代替脚本输出；脚本结果才是可核查的结果。
