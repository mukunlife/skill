# 参考资料导航

| 文档 | 何时必须读取 | 内容 |
|---|---|---|
| [rules.md](rules.md) | 每次整理前 | 输入格式、说话人识别、合并与配对规则、逐字保留要求、输出字段、异常处理 |
| [overview.md](overview.md) | 需要说明整理边界或向用户解释“为什么不改写”时 | 医疗文本整理的合规与准确性考虑、逐字保留的意义、与摘要式整理的区别 |

## 读取顺序

1. 先读 `rules.md`，据此检查输入格式和说话人别名。
2. 若用户要求“总结一下对话”或“给出诊疗建议”，先读 `overview.md` 的适用边界，说明本 Skill 不做这些事。
3. 输出后按 `rules.md` 的核验要求运行 `scripts/checks.py`。
