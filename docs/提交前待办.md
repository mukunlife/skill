如果远端仓库不存在或没有权限，先在 GitHub 网页新建一个 **Public** 空仓库（不要勾选
README），再改地址：

```powershell
git remote set-url origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```
