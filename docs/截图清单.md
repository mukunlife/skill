# 实验截图清单

保存位置：`docs/screenshots/`
截图工具：`Win + Shift + S`（截图后可直接标注），或 Snipping Tool。

## 通用要求

- **绝对不要截到完整 API 密钥**。截图前关闭 `settings.json` 标签页；CC Switch 里点眼睛图标隐藏密钥。
- 如已截到，用**实心黑框**完全覆盖，不要用半透明马赛克（可能被复原）。
- 每张图能看清窗口标题或路径，证明不是拼图。
- 文件名按下面编号命名，便于老师对照。

## 拍摄顺序建议

1. 先拍 1、2（配置与连接）。
2. 再拍 3、4、5（文件操作）。
3. 打开网页 Chat 拍 6。
4. 终端跑两个 `checks.py` 拍 7、8。
5. 推送成功后拍 10。
6. 最后补 9、11、12。

## 拍完后

```powershell
git add docs/screenshots
git commit -m "补充实验截图"

```
